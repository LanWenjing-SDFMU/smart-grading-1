# ImageMarkService 布局管理增强规范

## 1. 需求概述

为 `ImageMarkService` 增加智能布局管理功能，确保错误题目的解析文本框能够自动寻找不与已有元素重叠的位置放置，并绘制从题目到解析框的连线。

## 2. 技术方案

### 2.1 核心改动

1. **重构 `markImageWithUnifiedResult` 方法**：
   - 在遍历题目之前，收集所有题目的边界框作为不可覆盖区域（obstacles）
   - 维护已放置的解析框列表（usedAnnotationRects）
   - 调用新的 `drawAnnotationWithPlacement` 方法进行智能放置

2. **新增 `convertBBox` 辅助方法**：
   - 提取现有的坐标转换逻辑为独立方法
   - 处理归一化坐标（0~1000）到实际像素的转换
   - 处理边界裁剪

3. **新增 `drawAnnotationWithPlacement` 核心方法**：
   - 计算解析文本所需尺寸
   - 按优先级生成候选位置（右、下、左、上四个方向）
   - 使用碰撞检测找到第一个可用位置
   - 绘制半透明背景框、文本和连线
   - 返回实际放置的矩形用于后续碰撞检测

4. **新增 `isOverlapping` 碰撞检测方法**：
   - 检查矩形是否与列表中的任意矩形重叠

### 2.2 布局优先级

1. **右侧**（优先）：尝试在题目框右侧放置
2. **下方**：尝试在题目框下方放置
3. **左侧**：尝试在题目框左侧放置
4. **上方**：尝试在题目框上方放置
5. **降级位置**：若均无法放置，放在图片左上角

### 2.3 解析框样式

- 半透明白色背景 (`Color(255, 255, 255, 200)`)
- 红色边框
- 红色文字
- 从题目框右下角到解析框左上角的连线
- 连线端点绘制小圆点

## 3. 受影响文件

| 文件 | 改动类型 |
|------|---------|
| `ImageMarkService.java` | 修改现有方法 + 新增方法 |

## 4. 具体改动说明

### 4.1 `markImageWithUnifiedResult` 方法

**改动点**：
- 方法开头增加 obstacles 和 usedAnnotationRects 的初始化
- 遍历题目之前先收集所有题目边界框到 obstacles
- 将原有的 `drawUnifiedAnnotationsWithLine` 调用替换为 `drawAnnotationWithPlacement`
- 移除 `drawUnifiedAnnotations` 和 `drawUnifiedAnnotationsWithLine` 方法（不再需要）

### 4.2 `convertBBox` 方法（新增）

独立方法，处理：
- 归一化坐标转换（0~1000 → 实际像素）
- 边界裁剪（确保矩形在图片范围内）
- 无效矩形返回 null

### 4.3 `drawAnnotationWithPlacement` 方法（新增）

核心智能布局逻辑：
- 计算最大宽度：`min(图片宽度*30%, 400px)`，最小 150px
- 调用 `wrapText` 换行
- 生成四个方向的候选位置（每个方向尝试多个偏移量）
- 使用 `isOverlapping` 检测碰撞
- 绘制顺序：半透明背景 → 边框 → 文本
- 绘制连线：从题目框右下角到解析框左上角

### 4.4 `isOverlapping` 方法（新增）

简单碰撞检测：
- 遍历矩形列表
- 使用 `Rectangle.intersects()` 判断

### 4.5 `wrapText` 方法

保持不变，继续按字符逐字换行。

### 4.6 `drawMark` 方法

保持不变，已实现居中绘制。

## 5. 边界条件处理

| 场景 | 处理方式 |
|------|---------|
| questions 为空 | 返回原图 |
| bbox 无效（null 或宽高为0） | 跳过该题目 |
| 所有候选位置均被占用 | 降级放置在图片左上角 |
| 解析文本过长超出图片 | 自动换行，不超出图片范围 |

## 6. 预期效果

- 多个错误题目的解析框不会相互重叠
- 解析框优先放置在题目右侧，避免遮挡其他题目
- 连线清晰指向对应的解析内容
- 半透明背景提升文字可读性
